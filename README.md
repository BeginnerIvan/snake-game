# Snake Game 🐍

Классическая «Змейка» на чистом HTML5 Canvas + JavaScript. Без зависимостей и сборки.

## Запуск

Просто открой `index.html` в браузере. Всё.

## Управление

- **Стрелки** или **WASD** — движение
- **Пробел** — пауза
- Кнопка **«Заново»** — рестарт после проигрыша

## Возможности

- Подсчёт счёта и сохранение рекорда (localStorage)
- Защита от разворота на 180°
- Еда не появляется под змейкой

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка и точка входа |
| `style.css` | Стили |
| `script.js` | Логика игры |
